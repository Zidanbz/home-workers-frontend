# API Docs

Dokumentasi endpoint yang dipakai frontend.

## Isi Minimal per Endpoint

- Nama endpoint dan method.
- Tujuan endpoint.
- Header wajib (auth/content-type).
- Body request.
- Contoh response sukses.
- Contoh response error yang perlu ditangani UI.

## Template Cepat

Gunakan `docs/api/TEMPLATE.md` untuk endpoint baru.

## Dokumen Tersedia

- `docs/api/auth-register-login.md`: contract endpoint auth untuk flow registrasi dan login.
