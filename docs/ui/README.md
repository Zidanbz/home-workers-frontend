# UI Docs

Dokumentasi alur UI per fitur.

## Isi Minimal per Dokumen UI

- Nama flow/screen.
- Tujuan flow.
- Daftar state (loading, empty, success, error).
- Validasi form dan pesan error yang tampil.
- Navigasi masuk/keluar screen.

## Template Cepat

Gunakan `docs/ui/TEMPLATE.md` untuk flow baru.
